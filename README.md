# TodoForge AI

TodoForge AI is a modern AI-powered tool that generates fully functional Todo web applications instantly.

Users simply enter a prompt like "Create a todo app," and the system produces:

- HTML structure
- CSS styling
- JavaScript logic
- Responsive UI

## Features

- AI-powered Todo app generator
- Modern dark/light theme
- Fully responsive design
- Add, delete, mark complete tasks
- Smooth animations
- Live preview

## Tech Stack

- HTML
- CSS
- JavaScript

## How It Works

1. Enter the prompt "Create a todo app."  
2. Click "Generate App."  
3. Instantly preview the generated Todo app

- Netlify
