# 🚀 TodoForge AI

##### **TodoForge AI** is a modern AI-powered web application that generates a fully functional Todo list interface using clean HTML, CSS, and JavaScript.

This project demonstrates how simple prompts and structured logic can quickly produce a responsive, interactive task management application. The goal is to make productivity tools simple, fast, and accessible for everyone.

---

#### 🌐 Live Demo

🔗 **Try the App:**
[TodoForge AI](https://todo-forge-ai.vercel.app/)

---

#### ✨ Features

* 🧠 AI-inspired Todo app generator
* ➕ Add new tasks instantly
* ✅ Mark tasks as completed
* 🗑️ Delete tasks easily
* ♻️ Clear all tasks with one click
* 💾 Task persistence using LocalStorage
* 🎨 Modern and clean UI design
* 📱 Fully responsive across all devices
* ⚡ Smooth animations and interactions

---

#### 🛠️ Tech Stack

* **HTML5** – Application structure
* **CSS3** – Modern styling and responsive layout
* **JavaScript (Vanilla JS)** – Interactive functionality

---

#### ⚙️ How It Works

1. Enter a task in the input field
2. Click **Add Task** to add it to the list
3. Mark tasks as completed when finished
4. Delete individual tasks or clear the entire list

All tasks are automatically saved using **LocalStorage**, so they remain available after refreshing the page.
